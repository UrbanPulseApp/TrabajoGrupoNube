##  Cómo Ejecutar el Proyecto

### 1. Requisitos Previos

* Java 11
* Docker y Docker Compose
* Node.js 18+
* PostgreSQL 18

### 2. Levantar la Base de Datos (PostgreSQL)

```bash
docker compose up -d
```
